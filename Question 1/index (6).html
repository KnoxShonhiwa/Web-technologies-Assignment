The Internet is a worldwide network of interconnected computers and devices. It allows users to communicate, share information and access online services.

2. Fundamental Computer Network Concepts

A computer network is a group of connected computers that communicate and share resources.

  • LAN: Local Area Network covering a small area.
  • WAN: Wide Area Network covering a large geographical area.
  • IP Address: A unique address used to identify a device.
  • Protocol: A set of rules used for communication.
  • TCP/IP: Important protocols used for Internet communication.

3. URL and its Structure

URL stands for Uniform Resource Locator. It is the address used to locate a resource on the Internet.

Example: https://www.example.com/index.html

  • https: Protocol
  • www: Subdomain
  • example: Domain name
  • .com: Top-level domain
  • index.html: Webpage/resource

4. Domain Name

A domain name is a human-readable name used to access a website. It is easier to remember than an IP address.

Example: example.com

DNS converts the domain name into the corresponding IP address.

5. Web Browsers and Web Servers

A web browser is software used to access and display webpages. Examples include Chrome, Firefox, Edge and Safari.

A web server is a computer/software system that stores webpages and sends them to clients when requested.

6. Working Principle of a Website

  1. User enters a URL in the browser.
  2. DNS finds the IP address of the server.
  3. The browser sends a request to the web server.
  4. The server processes the request.
  5. The server sends HTML, CSS and JavaScript files.
  6. The browser renders the webpage for the user.
